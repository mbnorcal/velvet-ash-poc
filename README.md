# The Velvet Ash — S01E01 "Notes of Cedar" (proof of concept)

An 84-second animatic produced autonomously on 24 October 2026 as the Phase 1 proof of concept for an AI-operated animated sitcom studio: three original characters in a neighborhood cigar lounge, seven camera compositions, reaction holds and a confessional, synthetic voices (free local TTS), procedurally drawn art. Static poses by design; see the production report in the source repository.
